5.1用 CSS Profile 名单筛出给国际生资助的学校：2027-28 年有 183 个学校和项目在「International Students」一栏标了 Yes

证据等级 A · 数字截至 2026 年 10 月 · 更新于 2026-10-15
证据 A花少量钱用时中等要一点毅力收益大
说人话：CSS Profile 是 College Board 的助学金申请表，很多美国大学用它算你家能出多少钱。打开它的参与学校名单，把「CSS Profile – International Students」这一栏选成 Yes，剩下的就是要国际生交这张表申请资助的学校和项目，2027-28 年有 183 个。第一所学校 25 美元，之后每所 16 美元。

收益

College Board 的 2027-28 参与学校名单（Participating Institutions and Programs）共列了 260 个学校和项目。名单有一栏叫「CSS Profile – International Students」，可以筛 Yes 或 No。2026 年 10 月 15 日筛 Yes，共 183 个，里面也有研究生院和奖学金基金会。哈佛、耶鲁、Amherst、Dartmouth、Bowdoin、Brown、康奈尔、西北、斯坦福、范德堡都标了 Yes。MIT 和普林斯顿不在名单上，它们用学校自己的表。College Board 写明：CSS Profile 申请第一所学校 25 美元（约 168 元人民币），每加一所 16 美元（约 108 元人民币）。自动免费的对象是“Domestic undergraduate students”（美国国内本科生），条件之一是家庭调整后总收入低于 100,000 美元。College Board 写明，你可以用本国货币填写，提交后自动换算成美元。它的国际申请人页面写明，很多大学给国际生发学校自己的助学金（institutional financial aid）。CSS Profile 首页已经开放 Fall 2027/Spring 2028 的申请入口。学校这边：哈佛写明，付不起费用或所在国家 College Board 收不了款的国际生，可以走替代流程。Bowdoin 和 Northwestern 写明，可以改交学校自己的国际生资助申请表（ISFAA 或 ISAFA）。

成本和门槛

每加一所学校就多交一笔费用。你要填家里的收入、资产和开销。很多学校还要你通过 IDOC（College Board 的材料上传系统）交父母的收入证明。College Board 的自动免费只给美国国内的本科生。

备注：拿钱之前先看绳子

CSS Profile 首页有一个“Check Participating Schools and Scholarships”按钮，点开就是参与学校名单。标 Yes 只说明这所学校要国际生交 CSS Profile 来申请资助，不说明给多少、录取看不看钱。这些要去学校自己的国际生资助页核实，见第 2、3 条。截止日期按每所学校自己的规定。Bowdoin 和康奈尔的页面写明，CSS Profile 每年 10 月 1 日开放。
