# 高性价比人生指南 · 海外版：拿钱出国

**不是你花钱去留学，是你拿钱去留学。**

这份指南只讲一件事：怎么不花钱、甚至拿着钱出国学东西。蓝领、白领都有路，从学手艺、学护理，到读本科、硕士、博士，都写到了。

一共 45 条，分 4 节。每条都写明你要付出什么、能换回什么、证据有多硬。来源只用各国政府、政府机构和使领馆、法律原文、公立大学官网，以及政府委托或出资运营的项目官网（比如 DAAD、魁北克的 boursesqma.com），不引中介、媒体和自媒体。全书共 150 条来源链接，每节的[核实记录](docs/核实记录/)列出了支撑每个数字的原文短句。

> 这是读者做的**非官方**衍生作品。灵感来自 GitHub 上的[《高性价比人生指南》](https://github.com/eternity4719/HowToLiveBetter)（eternity4719，CC BY 4.0）。原书第 23 节写了「培训优先走政府补贴」，但只写了国内。本仓库补的是国外这一块，和原作者没有关系，内容由本仓库自己负责。

**数字截至 2026 年 10 月。** 奖学金和签证政策每年都改，名额、金额、截止日期都可能变。申请前，照每条的来源链接自己再查一遍，以官方最新页面为准。发现写错了，欢迎提 issue。

## 先看这三句

1. **真正的门槛通常不是钱，是语言。** 德语、日语、捷克语、波兰语学好了，很多路就是免费的，甚至倒给你钱；魁北克的手艺奖学金要的是法语。用英语授课的项目大多要收学费。
2. **拿钱之前，先看清绳子。** 有的钱要你回国服务，有的要你在当地干满几年，不然要还。每条的「备注」都写了。
3. **全程自己能办。** 每条写的都是官方网站，自己就能查、能申请。不需要先给中介交钱。

## 拿了钱要付出什么：几根常见的绳子

| 绳子 | 例子 |
|---|---|
| 学成后必须回国服务 | 国家公派留学，要按期回国服务，CSC 另一项目的问答写明服务期两年（第 3 节第 1 条）；英国志奋领，读完回国至少两年（第 3 节第 6 条） |
| 必须在当地工作满几年，否则要还钱 | 大阪介护福祉士修学资金，在府内干满 5 年免还（第 1 节第 5 条）；冈山县养老院奖学金，没干满 5 年县里要收回补贴（第 1 节第 6 条） |
| 毕业后在当地工作几年 | 新加坡教育部学费补贴，要在新加坡工作 3 年（第 2 节第 11 条） |
| 没有服务期 | 魁北克职业培训奖学金（第 1 节第 1 条）；韩国 GKS、Erasmus Mundus 等（见第 3 节各条备注） |

## 证据分级

- **A**：官方原文直接写明了数字或规定。本书 29 条。
- **B**：官方有依据，但金额因地区、学校、合同而不同，或者要推算。本书 16 条。
- **C**：经验或共识，没有官方原文。本书 0 条。

## 别白费劲

有些很有名的奖学金不收中国大陆申请人，比如 Australia Awards、新西兰 Manaaki、美国富布赖特外国学生项目。有些国家以前免学费，现在不免了，比如挪威（2023 年秋季起收费）。详见第 2 节第 12、13 条和第 3 节第 15 条。
